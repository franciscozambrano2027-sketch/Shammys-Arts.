# Shammy's Arts — catálogo reorganizado

El proyecto ahora utiliza únicamente las categorías para las que existen fotografías reales:

- Tazas personalizadas (259 fotos)
- Set Combos (46 fotos)
- Cajas Premium (21 fotos)
- Detalles Scrap (11 fotos)
- Papelería Creativa (11 fotos)
- Productos Sublimables (30 fotos)

Se eliminaron del catálogo las secciones sin fotografías reales: camisetas/textiles, cojines, llaveros/accesorios, rompecabezas y termos/botellas.

La portada usa fotografías reales, las categorías tienen galerías completas con carga progresiva y lightbox, y las imágenes son responsivas y lazy-loaded.
